ACADEMIC RECORD MANAGER — SECOND PROJECT VERSION

Files:
- app.py: Streamlit app, CSV operations, record forms, and summaries.
- academic_records.csv: Separate synthetic dataset with 120 records.
- generate_dataset.py: Optional dataset generator; it overwrites the CSV.
- requirements.txt: Python package list.

Run in VS Code:
1. Extract the ZIP.
2. Open Friend_Academic_Record_Manager in VS Code.
3. Open Terminal > New Terminal.
4. Install packages: py -m pip install -r requirements.txt
5. Start app: py -m streamlit run app.py

Keep app.py and academic_records.csv together in this folder.
The application saves changes automatically to academic_records.csv.
